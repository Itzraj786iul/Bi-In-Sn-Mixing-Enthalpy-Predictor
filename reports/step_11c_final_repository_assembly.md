## F. Dependency / reproducibility warnings

1. **`scipy` undeclared.** It is imported directly by `step_5`, `step_7` and `step_9` but is not listed in `requirements.txt`. It is currently installed only as a transitive dependency of `scikit-learn`. Recommend adding `scipy` (unpinned, matching the file's style).
2. **`markdown` and `xhtml2pdf` undeclared.** `md_to_pdf_progress_report.py` needs them; they are missing from `requirements.txt`. This only matters if the progress-report generator is included.
3. **No version pins** in `requirements.txt` or `web/backend/requirements.txt`. The repository contains no evidence of the exact versions used, so none were added. Results depend on numerically stable `lstsq`/`LinearRegression` and are unlikely to vary, but exact reproducibility is not guaranteed. The frontend is pinned through the tracked `package-lock.json`.
4. **No Python version recorded** (no `runtime.txt`, `.python-version` or `pyproject.toml`). The local cache shows CPython 3.10. Some scripts use `zip(strict=True)`, which needs Python ≥ 3.10; this is not documented.
5. **Backend imports `src/rkm_model.py`** (`web/backend/comparison.py`), so the backend must run with the repository root available. That is the current Render setup; this is a documentation note only.
6. `npm run build` warns about chunks over 500 kB (Plotly). This is harmless.
